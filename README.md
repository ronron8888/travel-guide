# 旅行しおりテンプレート

スマートフォン・PCで見やすい旅行しおりのWebテンプレートです。

## 内容を変更する

旅行ごとの内容は `data.js` にまとめています。ここを書き換えるだけで、同じデザインを別の旅行に使えます。

- 旅行名・日程
- 参加者
- 集合場所
- スケジュール
- 地図リンク
- ホテル
- 食事・観光スポット
- 持ち物
- 連絡先

メイン画像は `assets/hero.jpg` に配置します。

## GitHub Pages

GitHubリポジトリの Settings → Pages で、Build and deployment を `Deploy from a branch`、Branch を `main` / `/ (root)` に設定すると公開できます。
